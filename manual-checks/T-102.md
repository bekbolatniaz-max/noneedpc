# T-102 · два телефона в одной игре (~10 мин)

Нужна игра с **локальным кооперативом** (в Steam метки «Local Co-op» / «Shared/Split Screen»). Terraria и Lethal Company на ПК так не умеют.

1. Ноутбук: `python -m server --host 0.0.0.0`.
2. Телефон 1 подключён как обычно → плашка «Игрок 1».
3. Телефон 1: плашка → меню → «+ Игрок». Телефон 2 (та же Wi-Fi) открывает показанную ссылку → плашка «Игрок 2».
4. `joy.cpl` на ноутбуке: два «Controller (XBOX 360 For Windows)».
5. В игре: второй игрок нажимает A/Start, чтобы присоединиться; оба управляют своими персонажами.

Результаты: ☐ два геймпада в joy.cpl ☐ номера на телефонах совпадают с игрой ☐ оба играют одновременно
