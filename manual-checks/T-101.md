# T-101 · ручные проверки (лидер, iPhone 15 + Samsung UE43N5300)

## A. Геймпад виден в Windows и Steam (~3 мин, после установки ViGEmBus)
1. `python -m server --host 0.0.0.0` — в консоли **нет** строки «бэкенд vigem недоступен».
2. Подключить телефон (мок-PWA или любой клиент) — в «Панель управления → Устройства и принтеры» появился «Xbox 360 Controller».
3. Steam → Настройки → Контроллер → геймпад виден, кнопки и стики реагируют.
4. Закрыть вкладку на телефоне — через ~0,25 с всё отпущено (персонаж не бежит сам).

## B. Режим приставки, пробный прогон (~2 мин)
1. HDMI в ТВ, на ТВ «Игровой режим».
2. `.\scripts\console-mode.ps1 -Action on -DryRun` — план из 4 шагов, ничего не изменилось.
3. Если план устраивает: в `config/local.yaml` → `console_mode: { dry_run: false }`.

## C. Режим приставки по-настоящему (~3 мин)
1. С телефона `POST /api/v1/console-mode {"state":"on"}` (или кнопка в PWA).
2. Картинка только на ТВ, открылся Big Picture, звук идёт с ТВ (если нет — переключить вручную, это M2).
3. `{"state":"off"}` — экран ноутбука вернулся, Big Picture закрыт.

## D. Играем (~10 мин)
1. Режим приставки вкл → запустить Terraria с телефона.
2. Пройти начало: ходьба, прыжок, атака, инвентарь. Оценка задержки «на глаз»: ☐ незаметна ☐ терпимо ☐ мешает.
