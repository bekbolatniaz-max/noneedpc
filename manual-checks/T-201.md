# T-201 · ручная проверка PWA на iPhone 15 (лидер, ~5 мин)

1. Ноутбук: `python -m server --host 0.0.0.0` (или мок: `python -m server.mock --host 0.0.0.0`). Брандмауэр — только «Частные сети».
2. iPhone в той же Wi-Fi → Safari → адрес из консоли сервера + `#pair=<код>` (или открыть адрес и ввести код).
3. Повернуть горизонтально. Поделиться → «На экран Домой» → открыть с иконки (полный экран, без панели Safari).
4. Держать левый стик и одновременно жать A — оба работают (мультитач). Индикатор: зелёная точка, RTT в мс.
5. Плашка статуса → меню: игры с обложками, «Приставка вкл/выкл», запуск игры.

Важно: в iOS включить «Автоблокировка» = «Никогда» на время игры (Wake Lock появится с HTTPS в M2).
