# T-001 · ручная проверка: мок доступен с телефона

Кто: друг (Pixel) или лидер (iPhone) · Время: ~3 минуты

1. На ноутбуке: `python -m server.mock --host 0.0.0.0 --pair-code 123456`. Запомнить адрес из строки `http://192.168.x.x:8765/`.
2. Если Windows спросит про брандмауэр — разрешить **только для частных сетей**. Wi-Fi дома должен быть «Частная сеть».
3. Телефон в той же Wi-Fi: открыть `http://192.168.x.x:8765/api/v1/info`.
4. Ожидается JSON с `"protocol_version": 1` и `"mock": true`.
5. Остановить сервер `Ctrl+C`.
