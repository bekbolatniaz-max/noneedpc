# T-102 · Локальный мультиплеер: несколько телефонов в одной игре

Ветка: `feat/be-T102-multiplayer` · Исполнитель: лидер · Проверка: Codex

## Критерии
- **AC-1** (auto) Каждый сопряжённый телефон получает свой слот и свой виртуальный Xbox 360; ввод слотов независим (e2e на ViGEm через XInput).
- **AC-2** (auto) Номер игрока = XInput user index из уведомления драйвера (`led_number`) + 1; телефон получает WS-событие `player`; уведомления закрытого устройства игнорируются.
- **AC-3** (auto) `GET /api/v1/pair/code` (только с токеном) отдаёт текущий код и время жизни; контракт обновлён.
- **AC-4** (auto) PWA: «Игрок N» в плашке, «+ Игрок» — код и ссылка для второго телефона, список подключённых.
- **AC-5** (auto) `scripts/firewall.ps1 add|remove|status` с `-DryRun`: одно правило TCP 8765, только частная сеть и локальная подсеть.
- **AC-6** (manual) Два телефона в игре с локальным кооперативом — `manual-checks/T-102.md`.
