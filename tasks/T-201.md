# T-201 · PWA M1: сопряжение, экранный геймпад, игры, режим приставки

Ветка: `feat/fe-T201-pwa-m1` · Исполнитель: лидер (D-007) · Проверка: Codex

## Критерии
- **AC-1** (auto) Протокол: кадр 18 байт LE по контракту, `seq` по модулю 65536, один переиспользуемый буфер; PONG на PING с теми же байтами; RTT по своему PING; RUMBLE.
- **AC-2** (auto) Проверка `protocol_version` из `/info`; при несовпадении — понятное сообщение без подключения.
- **AC-3** (auto) Сопряжение: ввод кода или `#pair=` из QR (код сразу убирается из адреса); токен только в `localStorage` и заголовке; 4401 → повторное сопряжение.
- **AC-4** (auto) Геймпад: 2 стика, D-pad, ABXY, LB/RB, LT/RT, Start/Select/Home, L3/R3; мультитач; отправка при изменении + 60 Гц, пока палец на экране; всё отпускается при сворачивании.
- **AC-5** (auto) Меню: список игр с обложками (fetch с заголовком → blob), запуск, «Приставка вкл/выкл» с обновлением по WS-событию; скрытие по `features`.
- **AC-6** (auto) Безопасность: данные сервера только через `textContent`, нет `innerHTML`/внешних ресурсов/токена в URL и логах.
- **AC-7** (manual) iPhone 15 Safari: мультитач стик + кнопка, задержка «на глаз», safe-area — `manual-checks/T-201.md`.
