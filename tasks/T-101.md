# T-101 · M1: настоящий сервер — Steam, vigem, режим консоли

Ветка: `feat/be-T101-m1-mvp` · Исполнитель: лидер (Claude Code) · Проверка: Codex

## Цель
`python -m server --host 0.0.0.0` на ноутбуке: телефон сопрягается, видит игры Steam, запускает игру, управляет ей через виртуальный Xbox 360; режим приставки включается с телефона с откатом.

## Критерии
- **AC-1** (auto) Steam: парсер VDF без eval; библиотеки из `libraryfolders.vdf`, игры из `appmanifest_*.acf` (только `StateFlags & 4`, скрыты служебные appid + `steam.hide_appids`), обложки из `appcache/librarycache` (новая и старая раскладка). Только чтение.
- **AC-2** (auto) Запуск: `steam://rungameid/<int appid>`, 404 для неизвестной/скрытой, 409 при повторном нажатии в течение 5 с и при ошибке открытия; событие `launch`.
- **AC-3** (auto) Плагин `vigem`: маска кнопок и стики/триггеры напрямую в XUSB-отчёт; вибрация из потока драйвера доходит до слота; закрытие отпускает всё; `available()` ничего не устанавливает. Ядро плагин не импортирует.
- **AC-4** (auto) Если выбранный бэкенд недоступен — сервер стартует на `mock` с явным предупреждением в консоли.
- **AC-5** (auto) `scripts/console-mode.ps1 on|off|status`: `-DryRun` ничего не меняет и не пишет снимок; `on` без ТВ отказывается (если нет `-Force`); снимок (экраны, таймауты сна/дисплея от сети) пишется до изменений; `off` восстанавливает из снимка. Последняя строка — JSON.
- **AC-6** (auto) `ScriptConsoleMode`: по умолчанию `dry_run: true`; ошибки скрипта → `state: error` с сообщением; события `console_mode`.
- **AC-7** (auto) Токены сопряжённых устройств переживают перезапуск: `data/paired-devices.json` (в .gitignore), только хэши, атомарная запись.
- **AC-8** (auto) Контракт: настоящий сервер проходит те же схемы; `/system*` → 404 при `features.system = false` (описано в OpenAPI).
- **AC-9** (manual) Лидер: ViGEmBus установлен, геймпад виден в Steam, уровень Terraria проходится с iPhone; режим приставки на Samsung UE43N5300 — `manual-checks/T-101.md`.
